## 💡 技巧

**不要追求"全自动一次生成完美"。** 官方看的是"过程讲不讲得清楚"，所以
**"我让它做了 v1，我发现 X 不行，于是我这样要求它改"这个叙事本身就是加分项** ——
它同时证明了你有能力判断和纠错。

所以第 4、5 号截图**不是可选的**，是把普通作品变成高分作品的关键。
