## Q1 · 这门机器学习课重点考哪几个概念？给出出处。

**期望答案**
重点集中在三个方面：① 泛化能力与训练/验证/测试的划分（§3.1）；② 正则化与模型选择，重点是正则化如何抑制过拟合、以及为什么必须用验证集而非测试集调参（§3.2）；③ 偏差-方差分解与欠拟合/过拟合的判别（§4.1），以及类别不平衡下应改用 F1、ROC-AUC、PR-AUC 而非准确率（§4.2）。

**期望引用**
```
[1] 《机器学习课程 · 第 3-4 章 讲义节选》 §3.2
   "任何时候都不要为了提升测试集分数而回头改模型选择策略，那是典型的信息泄漏。"
[2] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.1
   "判断依据：训练误差和验证误差都高 → 欠拟合；训练误差低但验证误差明显更高 → 过拟合。"
[3] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.2
   "此时应改用：查准率（Precision）、查全率（Recall）、以及二者调和平均的 F1。"
```

## Q2 · 最小二乘解和正交投影是什么关系？

**期望答案**
最小二乘就是在把 $b$ 正交投影到 $\mathrm{Col}(A)$ 上：最优残差 $b - A\hat x$ 与列空间正交，投影矩阵为 $P = A(A^TA)^{-1}A^T$。几何上的解释是——解 $\min\|Ax-b\|_2$ 等价于"找列空间里离 $b$ 最近的点"。由此可得一个经典诊断：最优残差与每一个特征列正交，所以**残差图不应呈现可识别的模式**。

**期望引用**
```
[1] 《线性代数复习提纲 · 三个必考结论》 §2.2
   "几何解释：当 A 列满秩时，Col(A) 是 R^m 的子空间，最优解就是把 b 正交投影到 Col(A) 上，残差 b - A x̂ 与列空间正交。"
[2] 《线性代数复习提纲 · 三个必考结论》 §2.2
   "推论（很重要）：最优残差与每一个特征列正交，即 Σ_i x_i (b_i - ŷ_i) = 0。这给出了'残差图应当没有可识别的模式'这一经典诊断。"
```

## Q3 · 模型过拟合了，我该调正则化还是换模型？

**期望答案**
先判断是不是过拟合：训练误差低、验证误差明显更高 → **方差主导**，此时优先**加大正则化强度**而不是换模型；反之若训练误差和验证误差都高，那是偏差主导（欠拟合），该加容量而不是加正则。方向搞反会让验证误差进一步变差。

**期望引用**
```
[1] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.1
   "欠拟合是偏差主导，过拟合是方差主导。判断依据：训练误差和验证误差都高 → 欠拟合；训练误差低但验证误差明显更高 → 过拟合。"
[2] 《机器学习课程 · 第 3-4 章 讲义节选》 §3.2
   "λ 越大，模型越简单、训练误差上升但泛化误差可能下降——这就是偏差-方差权衡的具体实现。"
```

## Q4 · 类别不平衡时，AUC 和准确率哪个更合适？为什么？

**期望答案**
**准确率不合适**，因为它会被多数类完全主导——一个"永远预测负类"的模型准确率可能高达 95% 却毫无价值。应改用 **ROC-AUC**（对正负样本比例不敏感，作为不平衡场景主指标），并常与 **PR-AUC** 一起汇报（后者在极度不平衡时更敏感）。另外训练阶段应用**类别权重或重采样**处理不平衡，**阈值不要用 0.5**，应在验证集上按业务代价选取。

**期望引用**
```
[1] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.2
   "当正负样本比例悬殊……一个'永远预测负类'的模型准确率可能高达 95%，却毫无价值。"
[2] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.2
   "ROC-AUC：它衡量模型在所有阈值下区分两类样本的能力，对正负样本比例不敏感，常作为不平衡场景的主指标。"
[3] 《机器学习课程 · 第 3-4 章 讲义节选》 §4.2
   "实践建议：训练时用类别权重或重采样处理不平衡；阈值不要用 0.5，而应在验证集上按业务代价选取。"
```
